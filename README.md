### 김기현 · Product Builder

**기획부터 운영까지, 제품을 끝까지 책임집니다.**

임베디드와 웹, AI 를 거친 12년차 개발자입니다. 팀장 · PM 으로 팀을 이끌면서 제품의 핵심 구조를 직접 설계하고 구현해 왔습니다.
고객의 이야기를 듣고 → 움직이는 데모로 빠르게 맞추고 → 출시 뒤 운영까지 함께합니다.
